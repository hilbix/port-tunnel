# port-tunnel

This tool was created with the help of ChatGPT. See [Transcript](transcript/transcript.md) (the transcript is in German language)

- This tunnels ports from one location to another.
- Start the tool at both ends, interconnect it and then you are set up
- Thanks to `go` you can compile it to binary of course

## Usage

	git clone https://github.com/hilbix/port-tunnel.git
	cd port-tunnel
	make

Everything else see [Transcript](transcript/transcript.md)
